# 任务三报告

## 1 参数的理解

### 1.1 G1OldCSetRegionThresholdPercent

```
通过-XX:G1OldCSetRegionThresholdPercent指定每轮Mixed GC回收的Region最大比例，默认10%，也就是每轮Mixed GC附加的Cset的Region不超过全部Region的10%，最多10%。
```

### 1.2 G1MixedGCCountTarget

```
指定一个周期内触发Mixed GC最大次数，默认值8。一次全局并发标记后，最多接着8次Mixed GC，把全局并发标记阶段生成的Cset里的候选 Region拆分为最多8部分，然后在每轮Mixed GC里收集一部分。
```

### 1.3 G1MixedGCLiveThresholdPercent

```
指定被纳入Cset的Region的存活空间占比阈值,目前默认值未85%。在全局并发标记阶段，如果一个Region的存活对象的空间占比低于此值，则会被纳入Cset。此值直接影响到Mixed GC选择回收的区域，当发现GC时间较长时，可以尝试调低此阈值，尽量优先选择回收垃圾占比高的Region，但此举也可能导致垃圾回收的不够彻底，最终触发Full GC。
```



## 2 参数的使用

### 2.1 G1OldCSetRegionThresholdPercent

G1OldCSetRegionThresholdPercent用于MixedGC的时候，确定本轮GC最大的老区回收集（CSet）的Regions的数量。

```c++
// src/hotspot/share/gc/g1/g1Policy.cpp
uint G1Policy::calc_max_old_cset_length() const {
  // The max old CSet region bound is based on the threshold expressed
  // as a percentage of the heap size. I.e., it should bound the
  // number of old regions added to the CSet irrespective of how many
  // of them are available.

  const G1CollectedHeap* g1h = G1CollectedHeap::heap();
  const size_t region_num = g1h->num_regions();
  const size_t perc = (size_t) G1OldCSetRegionThresholdPercent;
  size_t result = region_num * perc / 100;
  // emulate ceiling
  if (100 * result < region_num * perc) {
    result += 1;
  }
  return (uint) result;
}
```

### 2.2 G1MixedGCCountTarget

G1MixedGCCountTarget用于MixedGC的时候，确定本轮GC最小的老区回收集的Regions的数量，它是基于候选Regions来决定的。参数也说明了，在Mixed GC的系列收集中，每次最小的回收集的数量是确定的，基于候选Cset的Regions数量来决定，而不是基于剩余的Regions数量来决定。

```c++
// src/hotspot/share/gc/g1/g1Policy.cpp
uint G1Policy::calc_min_old_cset_length(G1CollectionSetCandidates* candidates) const {

  const size_t region_num = candidates->num_regions();
  const size_t gc_num = (size_t) MAX2(G1MixedGCCountTarget, (uintx) 1);
  size_t result = region_num / gc_num;
  if (result * gc_num < region_num) {
    result += 1;
  }
  return (uint) result;
}
```

### 2.3 G1MixedGCLiveThresholdPercent

G1MixedGCLiveThresholdPercent主要影响入选候选集合的Region的数量

```c++
// src/hotspot/share/gc/g1/g1CollectionSetChooser.hpp
static size_t mixed_gc_live_threshold_bytes() {
    return HeapRegion::GrainBytes * (size_t) G1MixedGCLiveThresholdPercent / 100;
```

#### 3.4.2 版本2

对于每次Mixed GC来说，我们关心的其实是回收多少个Regions，这三个参数都是在为它服务的，可以根据每次Mixed GC中候选CSet的数量的增加或减少，来确定参数的增加或减少。

```
void G1Policy::update_other_g1_params(size_t candidates_region_num) {

    // 获取堆的全部region数量
    const G1CollectedHeap* g1h = G1CollectedHeap::heap();
    const size_t all_region_num = g1h->num_regions();

    // 这里是加入到候选集合的比例
    TruncatedSeq* candidates_seq = candidates_cset_seq();
    // 历史平均
    double history_avg_candidates =  candidates_seq->avg();
    record_or_add_candidates_cset_num(candidates_region_num);

    TruncatedSeq* region_seq = region_cset_seq();
    double history_avg_region_num = region_seq->avg();
    record_or_add_region_cset_num(all_region_num);

    double rate = 0.0;

    // 更新G1MixedGCCountTarget和G1OldCSetRegionThresholdPercent
    int diff_candidates = candidates_region_num - history_avg_candidates;
    if (diff_candidates < 0) {
        rate = ((-1.0) * diff_candidates) / (history_avg_candidates);
        uintx add = (uintx) rate * G1MixedGCCountTarget;
        G1MixedGCCountTarget = MIN2( G1MixedGCCountTarget + add,(uintx)12);

    } else {
        rate = (1.0 * diff_candidates) / history_avg_candidates;
        uintx reduce = (uintx) rate * G1MixedGCCountTarget;
        G1MixedGCCountTarget = MAX2( G1MixedGCCountTarget - reduce,(uintx)4);
    }

    int diff_region = all_region_num - history_avg_region_num;
    if (diff_region < 0) {
        rate = ((-1.0) * diff_region) / (history_avg_region_num);
        uintx reduce = (uintx) rate * G1OldCSetRegionThresholdPercent;
        G1OldCSetRegionThresholdPercent = MAX2( G1OldCSetRegionThresholdPercent - reduce,(uintx)5);
    } else {
        rate = (1.0 * diff_region) / history_avg_region_num;
        uintx add = (uintx) rate * G1OldCSetRegionThresholdPercent;
        G1OldCSetRegionThresholdPercent = MIN2( G1OldCSetRegionThresholdPercent + add,(uintx)25);
    }
}
```

对于G1MixedGCLiveThresholdPercent，需要在筛选候选Regions的时候就进行调整，所以在g1CollectionSetCandidates类中进行更新，找到当前region存活数据的平均值是一个比较好的选择，在平均值的基础上进行平滑更新，作为当前的G1MixedGCLiveThresholdPercent参数。

```
// src/hotspot/share/gc/g1/g1CollectionSetCandidates.cpp
void G1CollectionSetCandidates::verify() const {
  uint idx = _front_idx;
  uint curIndex = _front_idx;
  size_t sum_of_reclaimable_bytes = 0;
  HeapRegion *prev = NULL;
  size_t liveByte = 0;
  size_t reg_size = HeapRegion::GrainBytes;
  size_t regionTotalSize = (_num_regions - curIndex) * reg_size;

  for (; curIndex < _num_regions; curIndex++) {
    HeapRegion *cur = _regions[curIndex];
    liveByte += cur->live_bytes();
  }
  uint avg_live = ((liveByte * 100) / regionTotalSize);
  G1MixedGCLiveThresholdPercent = MAX2(MIN2((uintx)(avg_live * 7 + G1MixedGCLiveThresholdPercent * 3) / 10, (uintx)95), (uintx)50);

}
```

#### 3.4.3 版本3

这一版本会加入停顿时间，根据当前GC的预测停顿时间和历史停顿时间，做出相应的选择。

```
void G1Policy::update_other_g1_params(size_t candidates_region_num) {
	double predict_pause_time = _analytics->predict_total_pause_time_ms();
    double last_avg_total_pause_time = last_avg_total_pause_time_ms();
    record_last_avg_total_pause_time_ms(predict_pause_time);
    double eps = 0.000001;
    if (last_avg_total_pause_time < eps) {
        return;
    }
    const G1CollectedHeap* g1h = G1CollectedHeap::heap();
    const size_t all_region_num = g1h->num_regions();

    TruncatedSeq* candidates_seq = candidates_cset_seq();
    double history_avg_candidates = candidates_seq->avg();
    record_or_add_candidates_cset_num(candidates_region_num);

    TruncatedSeq* region_seq = region_cset_seq();
    double history_avg_region_num = region_seq->avg();
    record_or_add_region_cset_num(all_region_num);

    if (_g1h->gc_cause() != GCCause::_g1_periodic_collection) {
        // 使用停顿时间预测和历史数据动态调整增减比例
        double pause_factor = predict_pause_time / last_avg_total_pause_time; // 根据停顿时间调整比例
        pause_factor = MIN2(MAX2(pause_factor, 0.5), 2.0);
        double smoothing_factor = 3;
        // 更新G1MixedGCCountTarget
        int diff_candidates = candidates_region_num - history_avg_candidates;
        if (diff_candidates < 0) {
            double rate = (-1.0 * diff_candidates) / (history_avg_candidates);
            uintx add = (uintx)(rate  * pause_factor * G1MixedGCCountTarget);
            G1MixedGCCountTarget = MIN2((uintx)(G1MixedGCCountTarget * (10 - smoothing_factor) +  (G1MixedGCCountTarget + add) * smoothing_factor) / 10, (uintx)12);
        } else {
            double rate = (1.0 * diff_candidates) / (history_avg_candidates);
            uintx reduce = (uintx)(rate  * pause_factor * G1MixedGCCountTarget);
            G1MixedGCCountTarget = MAX2((uintx)(G1MixedGCCountTarget * (10 - smoothing_factor) +  (G1MixedGCCountTarget - reduce) * smoothing_factor) / 10, (uintx)6);
        }

        int diff_region = all_region_num - history_avg_region_num;
        if (diff_region < 0) {
            double rate = (-1.0 * diff_region) / (history_avg_region_num);
            uintx reduce = (uintx)(rate  * pause_factor * G1OldCSetRegionThresholdPercent);
            G1OldCSetRegionThresholdPercent = MAX2((uintx)(G1OldCSetRegionThresholdPercent * (10 - smoothing_factor) +  (G1OldCSetRegionThresholdPercent - reduce) * smoothing_factor) / 10 , (uintx)6);
        } else {
            double rate = (1.0 * diff_region) / (history_avg_region_num);
            uintx add = (uintx)(rate  * pause_factor * G1OldCSetRegionThresholdPercent);
            G1OldCSetRegionThresholdPercent = MIN2((uintx)(G1OldCSetRegionThresholdPercent * (10 - smoothing_factor) +  (G1OldCSetRegionThresholdPercent + add) * smoothing_factor) / 10 , (uintx)18);
        }
    }
}
```

利用预测的停顿时间和历史停顿时间做影响因子，理由如下：

如果当前GC预测的停顿时间大于历史停顿时间，说明当前有更多的垃圾收集，那么就应该收集更多的CSet，也就是G1MixedGCCountTarget减少的幅度会大一些，G1OldCSetRegionThresholdPercent增加的幅度大一些，每次GC收集的Region数量也多一点。
